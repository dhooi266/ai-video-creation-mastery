## What's here

A single self-contained page — no build step, no dependencies, no framework.

```
index.html           the whole page (HTML + CSS + inline SVG icons and artwork)
cover.png            hero banner
dac-logo.png         D Action Consultancy logo
thumb-ad.jpg         sample advertisement video thumbnail
thumb-mv.jpg         sample music video thumbnail
thumb-shortfilm.jpg  sample short film thumbnail
```

Fonts (Archivo, Spectral, IBM Plex Mono) load from Google Fonts. Everything else is local.

## Running it

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
